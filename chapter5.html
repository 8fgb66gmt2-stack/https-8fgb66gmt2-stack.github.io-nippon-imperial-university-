端末番号：R-03　／　設置：帝國大學中央研究資料室　／　最終稼働記録：帝國歴二百三十二年

竜棘國旧記録の照合後、附属図書館の旧式端末に一件の未登録研究記録が出現した。記録上、この端末は存在しないことになっている。

画面には研究者名の代わりに、ただ一つの識別子が表示されている。

NIPPON IMPERIAL UNIVERSITY / RESEARCH TERMINAL R-03
BOOT................. OK ARCHIVE LINK......... OK FOREIGN RECORD....... OK USER : UNREGISTERED CASE : M.D.-III STATUS: OPEN > identity lookup MIFUNEA DRACULA > historical status [REDACTED] > university affiliation KAMISHIRO HIJIRI / [NO RECORD] > warning THE TWO RECORDS MUST NOT BE MERGED.
端末管理者注記
「二つの記録を結合してはならない」という警告は、人物を別人として扱えという意味ではない。むしろ、同一人物か否かをまだ決めないまま調査を続けろという指示に見える。

研究端末には、三つの断片的な記録が残されている。

記録番号内容状態
R-03-Aミフネア・ドラキュラに関する竜棘國資料復元済
R-03-B神代聖の帝國大學在籍記録改竄痕あり
R-03-C二者を結ぶ私信・写真・蔵書記録暗号化

研究記録 R-03-A

「ミフネアについて、帝國側の研究者は一つの誤解を共有している。彼を『過去の人物』として扱うことだ。」

「竜棘國の記録から名前が消えた後も、彼に関する証言は別の名前で残った。」

「問題は、なぜ神代聖の署名が、その後の資料に現れるのかである。」

記録者不詳。末尾に手書きで「紅城院眞紅へ照会済」とある。

研究記録 R-03-B

神代聖の帝國大學在籍記録には、通常の履歴書には存在しない空白期間がある。

帝國歴二百二十年　六月　――　帝國歴二百二十二年　三月

この期間について、本人の履歴書は「国外研究」とのみ記す。しかし旅券記録、講演記録、寄贈書目には対応する資料が見つからない。

その空白の直後、神代文庫には「M. D.」の旧記録が登録されている。

研究主任の赤字
「人間を追うな。記録を追え。
人間は嘘をつく。記録も嘘をつく。
だが、二つの嘘が同じ場所で食い違ったとき、そこには事実が残る。」

研究記録 R-03-C / 復号前断片

暗号化されたデータの先頭に、紅城院眞紅の作品『夜侯』から引用されたと思われる一文がある。

「彼だけが過去を記憶し続ける。」

その直後に、研究端末の作成者自身による短いメモが続く。

「ならば、記憶している者の名前を変えればいい。
名前が変われば、歴史は別人を作れる。」

ENCRYPTED FILE / R-03-C
FILE : M.D._TO_K.H. KEY : _ _ _ _ _ HINT 01 : 第四章の旧記録を見よ。 HINT 02 : 「M. D.」は二文字ではない。 HINT 03 : 眞紅が彼を呼んだ「物語」の名を思い出せ。 ENTER KEY TO DECRYPT

―― 研究端末・復号鍵

第四章では「M. D.」の完全な名を確認した。第三章では眞紅が、その人物を文学の中で呼び続けた。

研究端末が要求しているのは人物名そのものではない。眞紅がミフネアを「過去を忘れられない者」として描いた作品の題名を入力せよ。

復号失敗。第三章の作品一覧を確認してください。
